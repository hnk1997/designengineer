Privacy

Updated November 2026

This site doesn’t ask for your name or sell your data. Here’s what it does collect.

Analytics

I use Google Analytics, through Google Tag Manager, to see how the site is used: which pages people visit, where they came from, and which buttons they tap. It sets cookies to recognise returning visitors. I don’t use it for advertising.

I also use Microsoft Clarity to see how people move through the site, with anonymous heatmaps and session recordings. Anything you type into Yalla is hidden from those recordings.

If you’re in Europe, analytics stays off unless you turn it on. Anywhere else, you can turn it off here.

Yalla, the AI assistant

What you type to Yalla is sent to an AI model run by Cloudflare so it can reply. I save chats for 30 days so I can read them and improve Yalla, then they’re deleted automatically. Only I can read them. They’re stored without your name or IP address, but they include anything you type. Analytics records that a chat happened, never what you typed.

To limit misuse, the site counts messages per visitor for a day, using a scrambled version of your IP address that can’t be read back. Please keep private information out of the chat.

WhatsApp and email

WhatsApp buttons open WhatsApp, usually with a message filled in for you to review. If you send it, WhatsApp’s own privacy policy applies, and I’ll use what you send to reply to you.

Hosting

The site runs on Cloudflare, which processes basic technical data, like IP addresses, to serve it securely.
